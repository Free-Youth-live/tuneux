============================================================
tuneux v__VERSION__ 使用手册
============================================================

本手册完整介绍 tuneux 的全部功能与操作方法。
tuneux 是「不羁的青春（FreeYouth）」的纯离线命令行音乐播放器，
用 Rust 编写，跨平台（Windows / macOS / Linux），界面与提示均为中文。

────────────────────────────────────────────

一、简介

- 核心格式纯 Rust 解码，无需任何系统编解码器：
  MP3 / FLAC / WAV / OGG / M4A / AAC / ALAC / Opus / WavPack。
- 扩展格式（APE / WMA / FLV / TAK / AC3 / DTS / DSD 等）在系统装有
  ffmpeg 时自动调用其解码，未装则跳过（详见「十二、FFmpeg 扩展格式」）。
- 纯离线：无任何联网功能、不收集任何数据。
- 单文件便携：把可执行文件复制到 U 盘即可随身携带（Linux系统除外），配置自动就近保存。

────────────────────────────────────────────

二、快速开始（三个系统首次运行）

【Windows】
  1. 解压 zip，双击 tuneux.exe。
  2. 若出现蓝色「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

【macOS】
  在「终端」里执行（把路径换成你的解压目录）：
    cd 解压目录
    xattr -cr tuneux
    ./tuneux

【Linux】
    chmod +x tuneux
    ./tuneux
  需要 libasound2（多数发行版已预装）。
  U 盘以 noexec 挂载时无法直接运行，请先复制到本地磁盘再 chmod +x。

三、界面布局（四段）

  ┌ 当前曲目 ───────────────┐ ┌ 电平 ───────┐
  │ 曲名 / 歌手 / 专辑 / 参数 │ │ 实时电平柱图 │   ← 顶部条
  ├────────────────────────┤ ├─────────────┤
  │ [浏览器 |] 播放列表      │ 频谱（半屏/全屏） │   ← 主区
  │           （封面 / 歌词）│                │
  ├────────────────────────┴────────────────┤
  │ [播] 曲名  0:03 ━━●━━ 3:43  100% 循环+随机 │   ← 状态条
  ├─────────────────────────────────────────┤
  │ ↑↓选曲 · Enter播放 · ←→±5s · v频谱 · q退出 │   ← 帮助栏
  └─────────────────────────────────────────┘

- 顶部条：左侧当前曲信息（标题、艺术家、专辑、编码格式·码率·采样率·位深），
  右侧实时电平表（左右声道柱图）。
- 主区：文件浏览器（b 键显隐）+ 播放列表；频谱、歌词、封面按需叠加。
- 状态条：播放图标、进度、时间、音量、循环/随机状态、临时提示与错误。
- 帮助栏：随当前焦点动态显示可用快捷键。

────────────────────────────────────────────

四、快捷键总表

【列表浏览】
  ↑ / ↓（或 k / j）   浏览列表（文件浏览器或播放列表，取决于焦点）
  Home / End          跳到列表顶部 / 底部
  Enter               浏览器：进入目录 / 播放文件
                      播放列表：播放选中曲 / 折叠·展开专辑组
  Backspace           浏览器：返回上级目录；播放列表：切回浏览器
  PageUp / PageDown   封面网格：整页翻动

【面板与视图】
  Tab                 切换焦点（文件浏览器 ↔ 播放列表）
  b                   显示 / 隐藏文件浏览器
  c                   切换封面（关 → 单封面 → 封面网格 → 关）
  v                   切换频谱（关 → 半屏 → 全屏 → 示波器）
  l                   显示 / 隐藏歌词
  g                   切换播放列表视图（平铺 ↔ 按专辑分组）

【播放控制】
  空格                播放 / 暂停
  ← / →               快退 / 快进 5 秒
  n / p               下一曲 / 上一曲
  r                   切换循环（关 → 单曲循环 → 列表循环）
  s                   切换随机播放
  + / -               音量增减

【播放列表管理】
  a                   加入播放列表（文件或整个目录，目录按专辑-曲序排序）
  d                   删除选中的曲目
  x                   清空播放列表（按两次确认，第二次须在 5 秒内）
  /                   搜索（浏览器按文件名递归搜索；播放列表按
                      曲名/歌手/专辑/路径）；Esc 退出搜索

【介质与其它】
  m                   切换介质风格（无 → 4 档磁带 → 4 档黑胶，只修饰声音）
  ?                   显示「关于」（版本号、简介、开源声明、版权），再按关闭
  q / Ctrl+C          退出（自动保存配置）

────────────────────────────────────────────

五、文件浏览器

- 按 b 键显示 / 隐藏左侧浏览器；Tab 在浏览器与播放列表间切换焦点。
- ↑↓（或 k/j）移动选中项，Home/End 到顶/底，Enter 进入目录或播放文件，
  Backspace 返回上级目录。
- 按 / 进入搜索：递归搜索当前目录下所有子目录的文件名，输入关键字即时过滤，
  Esc 退出。目录很大时收集在后台进行，期间可继续输入，结果到达即生效。
- Windows 下会跳过「隐藏 / 系统」属性目录（如 $RECYCLE.BIN、System Volume
  Information），并支持跨盘符导航：退到盘符根目录（如 C:\）后列出其它盘符，
  Enter 进入。

────────────────────────────────────────────

六、播放列表

- 按 a 键加入：选中文件则加入该文件；选中目录则递归加入目录下全部音乐文件
  （含 CUE 分轨展开），并按「专辑 - 曲序」自动排序。
- 按 d 删除选中曲目；按 x 清空（两次确认，防止误触）。
- 按 g 在「平铺」与「按专辑分组」间切换；分组视图下组头显示
  「专辑 - 歌手（N 首）（总时间）」，Enter 折叠 / 展开。
- 去重：配置 dedup_on_add = true 后，加入时跳过已在列表中的曲目。
- 断点续播：每首曲目记录播放进度，退出后自动保存，下次启动选中该曲按 Enter
  从上次位置继续。

────────────────────────────────────────────

七、面板

【专辑封面（c 键）】
- c 键三态循环：关 → 单封面 → 封面网格 → 关。
- 单封面：读取当前曲目标签内嵌封面，以终端字符渲染。
- 封面网格：按专辑分组展示缩略图，↑↓（k/j）选择、Enter 播放、PageUp/PageDown
  翻页；封面开启时会自动关掉文件浏览器（两者共用左侧位置）。

【歌词（l 键）】
- 优先加载歌曲同目录同名的 .lrc 文件；无则读取歌曲内嵌歌词标签。
- .lrc 自动识别 UTF-8 / UTF-16 / GBK / GB18030 编码。
- 显示在播放列表右侧，当前行高亮并随播放进度滚动。

【频谱（v 键）】
- v 键四态循环：关 → 半屏 → 全屏 → 示波器 → 关。
- 半屏 / 全屏：FFT 实时频谱（256 对数频段，Matrix 风格），全屏占满列表区。
- 示波器：左右声道波形（双边摆动）。

【电平表】
- 常驻顶部条右侧，显示左右声道实时电平柱图。

────────────────────────────────────────────

八、播放控制

- 空格播放 / 暂停；n / p 下一曲 / 上一曲；← / → 快退 / 快进 5 秒。
- r 循环三态：关（顺序播放）→ 单曲循环 → 列表循环。
- s 切换随机播放；+ / - 增减音量。
- 无缝播放（Gapless）：同采样率曲目间预载下一曲、无间隙衔接；采样率变化时
  自动降级为短间隙。
- 设备热切换：播放中拔插耳机 / 切换输出设备，约 2 秒内自动重连续播，无需重启。

────────────────────────────────────────────

九、介质风格（m 键）

m 键在 9 档间循环，只修饰声音（DSP）、不占界面：

  无 → 磁带·透明（高保真）→ 磁带·白色（清新）→ 磁带·深棕（经典）
     → 磁带·红色（老化）→ 黑胶·蓝色（低噪声）→ 黑胶·红色（高动态）
     → 黑胶·黑色（标准）→ 黑胶·彩胶（老化）→ 无 …

- 磁带：从新到旧，底噪 / 磁饱和 / 抖晃 / 掉粉逐渐加重，老磁带带周期带盘老化。
- 黑胶：从新到旧，底噪 / 唱针噼啪 / 槽纹磨损逐渐加重，老黑胶带周期偏心 wow。
- 当前档位写入 tuneux.toml 的 playback_medium，下次启动自动恢复；默认 none。

────────────────────────────────────────────

十、ReplayGain 响度归一

- 按 −14 LUFS 目标统一各专辑音量，默认关闭。
- 开启：在 tuneux.toml 设 replay_gain = true，下次播放生效。
- 首次播放某曲目时后台分析响度（无增益），第二次起自动应用增益；
  曲目播完 / 无缝切曲均会记录分析结果，重启后缓存仍在。

────────────────────────────────────────────

十一、自定义键位（keymap）

在 tuneux.toml 的 [keymap] 段可重映射播放控制键。动作名：

  toggle_play（播放/暂停）、next（下一曲）、prev（上一曲）、
  volume_up（音量+）、volume_down（音量−）

键描述语法：[shift+][ctrl+][alt+]<键名>，键名为单字符或
space / tab / enter / esc / backspace / up / down / left / right / home / end。

示例：
  [keymap]
  toggle_play = "ctrl+p"
  next = "ctrl+n"
  prev = "ctrl+b"
  volume_up = "shift+="

非法键描述会被忽略并回退默认键，不会导致启动失败。

────────────────────────────────────────────

十二、系统媒体键

- Linux：经 MPRIS（桌面媒体键自动路由，GNOME / KDE 均可）。
- Windows：用低层键盘钩子捕获媒体键，终端在后台也能控制。
- macOS：因需 app bundle，暂不支持。
- 可用 media_keys_enabled = false 关闭。

────────────────────────────────────────────

十三、FFmpeg 扩展格式（可选）

- 核心格式不需要 ffmpeg：MP3 / FLAC / WAV / OGG / M4A / AAC / ALAC /
  Opus / WavPack 全部纯 Rust 解码，自带、零依赖。
- 扩展格式：APE / WMA / FLV / TAK / AC3 / DTS / DSD（DSF/DFF）等，
  检测到系统 ffmpeg 就自动调用其解码，未装则跳过并提示，无需任何配置。
- 安装：
  Windows：winget install ffmpeg（或到 ffmpeg.org 下载解压后把 bin 加入 PATH）
  macOS：  brew install ffmpeg
  Linux：  Debian/Ubuntu：sudo apt install ffmpeg
           Fedora：sudo dnf install ffmpeg
           Arch：sudo pacman -S ffmpeg
- 安装后新开终端执行 ffmpeg -version 验证。
- 只放扩展格式才需要 ffmpeg，不装不影响核心格式全部功能。

────────────────────────────────────────────

十四、配置与数据文件

【配置文件 tuneux.toml】
  保存音量、循环、随机、列宽（browser_ratio）、上次浏览目录、界面状态
  （频谱/歌词/浏览器/封面开关）、介质风格、ReplayGain、键位、媒体键开关等。

【播放状态 playlist.toml】
  保存播放列表、每首曲目的断点续播进度、ReplayGain 缓存。

【存储位置】
  默认：可执行文件同目录（适合 U 盘随身带，单文件即完整播放器）。
  回退：同目录不可写时改存系统目录——
    Windows：%APPDATA%\tuneux\
    macOS：  ~/Library/Application Support/tuneux/
    Linux：  ~/.config/tuneux/

【常用配置项】
  volume            音量（0~1）
  replay_gain       ReplayGain 开关（true / false）
  repeat            循环模式（off / one / all）
  shuffle           随机播放（true / false）
  playback_medium   介质风格（none / tape-* / vinyl-*，旧短名 tape/vinyl 兼容）
  browser_ratio     浏览器与播放列表的列宽比例
  dedup_on_add      加入播放列表时去重
  media_keys_enabled 系统媒体键开关
  keymap            自定义键位表

退出（q）时自动保存；直接关窗口也会每 5 秒自动保存一次。
