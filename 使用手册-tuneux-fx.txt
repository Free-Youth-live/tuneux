============================================================
tuneux-fx v__VERSION__ 使用手册
============================================================

本手册完整介绍 tuneux-fx 的全部功能与操作方法。
tuneux-fx 是「不羁的青春（FreeYouth）」的插件版播放器：在 tuneux
的全部功能之上，新增 WASM 插件系统（均衡器 / 压缩器）、菜单栏、
命令模式、m3u、书签、歌词偏移等能力。纯离线，不收集任何数据。

────────────────────────────────────────────

一、tuneux-fx 与 tuneux 的关系

- tuneux-fx 包含 tuneux 的全部功能：格式支持、无缝播放、设备热切换、
  系统媒体键、ReplayGain、CUE 分轨、歌词、频谱/示波器/电平表、
  介质风格等（本手册「三、基础功能」完整列出）。
- 新增（仅 tuneux-fx）：WASM 插件系统、菜单栏、命令模式、
  m3u 保存/载入、书签、歌词偏移、主题切换、打开文件/目录、插件面板。

────────────────────────────────────────────

二、快速开始（三个系统首次运行）

【Windows】
  1. 解压 zip，双击 tuneux-fx.exe。
  2. 若出现蓝色「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

【macOS】
  在「终端」里执行（把路径换成你的解压目录）：
    cd 解压目录
    xattr -cr tuneux-fx
    ./tuneux-fx

【Linux】
    chmod +x tuneux-fx
    ./tuneux-fx

【插件目录 plugins/】
  压缩包内含 plugins/ 目录（均衡器 / 压缩器插件 + 官方签名）。请保持
  plugins/ 与 tuneux-fx 可执行文件在同目录，启动时自动加载；移走 plugins/
  则插件不可用，其余功能不受影响。

四、基础功能（与 tuneux 完全一致）

【快捷键（基础，fx 全部继承）】
  ↑ / ↓（或 k / j）   浏览列表（浏览器或播放列表，取决于焦点）
  Home / End          跳到列表顶部 / 底部
  Enter               浏览器：进入目录 / 播放文件
                      播放列表：播放选中曲 / 折叠·展开专辑组
  Backspace           浏览器：返回上级目录；播放列表：切回浏览器
  PageUp / PageDown   封面网格：整页翻动
  Tab                 切换焦点（文件浏览器 ↔ 播放列表）
  b                   显示 / 隐藏文件浏览器
  c                   切换封面（关 → 单封面 → 封面网格 → 关）
  v                   切换频谱（关 → 半屏 → 全屏 → 示波器）
  l                   显示 / 隐藏歌词
  g                   切换播放列表视图（平铺 ↔ 按专辑分组）
  空格                播放 / 暂停
  ← / →               快退 / 快进 5 秒
  n / p               下一曲 / 上一曲
  r                   切换循环（关 → 单曲循环 → 列表循环）
  s                   切换随机播放
  + / -               音量增减
  a                   加入播放列表（文件或整个目录）
  d                   删除选中的曲目
  x                   清空播放列表（按两次确认，第二次须在 5 秒内）
  /                   搜索（浏览器按文件名递归；播放列表按曲名/歌手/专辑/路径）
  m                   切换介质风格（无 → 4 档磁带 → 4 档黑胶）
  ?                   显示「关于」，再按关闭
  q / Ctrl+C          退出（自动保存配置）

【文件浏览器】b 键显隐；↑↓ 移动、Enter 进目录/播放、Backspace 返回；
  / 递归搜索；Windows 跳过隐藏/系统目录并支持跨盘符。

【播放列表】a 加入（目录递归 + 按专辑-曲序排序）、d 删除、x 清空；
  g 平铺/分组；dedup_on_add 去重；断点续播。

【面板】封面 c 三态（单封面 / 封面网格）、歌词 l（.lrc 同目录同名 +
  内嵌，自动识别编码）、频谱 v 四态（半屏 / 全屏 / 示波器）、电平表常驻顶部。

【播放】空格播放/暂停、n/p 切曲、←/→ ±5 秒、r 循环、s 随机、+/- 音量；
  无缝播放（Gapless）；设备热切换自动重连。

【介质风格】m 键 9 档：无 → 磁带×4（透明/白色/深棕/红色）→ 黑胶×4
  （蓝色/红色/黑色/彩胶）；只修饰声音，不占界面；档位随配置持久化。

【ReplayGain】按 −14 LUFS 统一音量，默认关闭；可在「设置 › ReplayGain
  响度归一」开关，或配置文件设 replay_gain = true；首次播放分析、第二次生效。

【系统媒体键】Linux 经 MPRIS；Windows 低层键盘钩子；macOS 暂不支持；
  可用 media_keys_enabled = false 关闭。

【FFmpeg 扩展格式】核心格式纯 Rust 解码；APE / WMA / FLV / TAK / AC3 /
  DTS / DSD 等在有系统 ffmpeg 时自动调用，未装则跳过。

────────────────────────────────────────────

五、菜单栏（F10 / 数字 1-8）

- 按 F10 或直接按数字 1-8 打开对应栏；↑↓←→ 在菜单项间移动，
  Enter 执行，Esc 关闭。
- 八栏：

  1 文件   打开文件…(F3) / 打开目录…(F4) / 退出(q)
  2 播放   播放/暂停(空格) / 上一曲(p) / 下一曲(n) / 循环(r) / 随机(s) / 音量(+/-)
  3 介质   9 档介质风格逐档选择
  4 视图   文件浏览器(b) / 专辑封面(c) / 歌词(l) / 频谱(v) / 播放列表分组(g)
  5 工具   均衡器(F9) / 压缩器 / DSP(灰) / 标签编辑(灰) / 格式转换(灰) / 封面管理(灰)
  6 设置   输出设备(自动跟随) / ReplayGain 响度归一 / 配色切换(F2)
  7 插件   均衡器 / 压缩器（已加载项带 √）
  8 帮助   快捷键速查 / 关于

- 灰显项为尚未实现的功能占位，不隐藏、不可选。

────────────────────────────────────────────

六、命令模式（: 键）

按 : 键底部出现命令输入框，输入命令回车执行，Esc 退出。支持的命令：

  quit / q / exit        退出程序
  volume <0-100>         设置音量（百分比）
  theme                  切换配色主题（同 F2）
  repeat off|single|list 设置循环模式（one/all 兼容）
  save-m3u              保存当前列表为 m3u（存到浏览器当前目录）
  load-m3u [路径]       载入 m3u（缺省用浏览器当前目录的 playlist.m3u）
  open-file <路径>       打开文件（整轨旁同名 .cue 自动分轨）
  open-dir <路径>        打开目录（递归收集加入播放列表）
  bookmark               在当前位置加书签
  bookmarks              列出书签
  bookmark-jump <序号>   跳到书签（序号从 0 起）
  bookmark-del <序号>    删除书签
  help / about           显示帮助/关于

────────────────────────────────────────────

七、插件系统

- WASM 插件宿主：插件为 .wasm 字节码，运行在沙箱内（内存/燃料配额），
  能力默认拒绝，只按 manifest 声明授予。
- Ed25519 验签三态：已认证 / 已签名·作者未知 / 未签名；第一方插件
  必须通过官方公钥验签才加载。
- 插件目录 plugins/：启动时读取 exe 同目录 plugins/；均衡器与压缩器
  自动加载，面板里 u 键卸载、再按重载（插入↔拔出）。
- 动态多槽位：均衡器、压缩器各 8 槽，同类效果器可叠加。
- 加载核查日志：插件加载/验签结果写入 tuneux-fx-plugins.log（追加式）。

────────────────────────────────────────────

八、均衡器面板（F9）

- F9 打开 / 关闭；未加载插件时面板仍可打开（显示未加载，按 u 加载）。
- 按键：
  ↑ / ↓       当前段增益 ±1 dB（10 段，±12 dB 范围）
  ← / →       选择段（左移 / 右移）
  e           旁路（临时关闭均衡器，保留参数）
  r           恢复默认（10 段增益归零）
  u           卸载 / 重新加载插件（释放/重新占用槽位）
  Esc         关闭面板

────────────────────────────────────────────

九、压缩器面板

- 从「工具 › 压缩器」或「插件 › 压缩器」打开，Esc 关闭。
- 按键：
  ↑ / ↓       当前参数增减
  ← / →       切换参数（共 5 个：阈值 / 压缩比 / 启动 / 释放 / 补偿增益）
  e           旁路
  r           恢复默认
  u           卸载 / 重新加载插件
  Esc         关闭面板

────────────────────────────────────────────

十、打开文件 / 打开目录（F3 / F4）

- F3 打开文件：状态栏进入命令框并预填 open-file，补全路径回车执行；
  也可直接 : 输入 open-file /完整/路径。
- F4 打开目录：同 F3，预填 open-dir，递归收集目录下音乐并加入播放列表。
- 打开文件会加入并立即播放；路径不存在或类型不符会提示，不影响现有列表。

────────────────────────────────────────────

十一、m3u 播放列表（保存 / 载入）

- 保存：浏览器导航到目标目录，: 输入 save-m3u 回车，存为「该目录/playlist.m3u」。
- 载入：浏览器导航到 m3u 所在目录，: 输入 load-m3u；或 load-m3u /完整/路径.m3u。
- 细节：整轨只写一行（CUE 归并）；载入时同名 .cue 自动展开；去重跟随配置；
  失效路径由「无法播放自动跳下一曲」处理。

────────────────────────────────────────────

十二、书签

- 加书签：播放到目标位置，: 输入 bookmark（或 bm）。
- 列书签：: 输入 bookmarks（或 bm-list）。
- 跳转：: 输入 bookmark-jump 序号（或 bm-jump 序号），序号从 0 起。
- 删除：: 输入 bookmark-del 序号（或 bm-del 序号）。
- 同一首歌重复加书签 = 更新位置；书签随播放列表持久化。

────────────────────────────────────────────

十三、歌词偏移（[ 与 ]）

- 按 [ 歌词提前 0.5 秒；按 ] 歌词延后 0.5 秒；状态栏提示「歌词偏移 ±0.5s」。
- 偏移量随配置持久化，退出重开仍在。

────────────────────────────────────────────

十四、主题切换（F2）

- F2 在两套内置配色间切换：DOS 复古（深蓝底、双线青框、黄色功能键号，
  默认）↔ 现代干净（跟随终端默认色、单线框）。
- 也可 : theme 或「设置 › 配色切换」；选择随配置持久化。

────────────────────────────────────────────

十五、配置与数据文件

【配置文件 tuneux-fx.toml】
  与基础版 tuneux 的 tuneux.toml 分离，避免互覆盖。保存音量、循环、随机、
  列宽、界面状态、介质风格、ReplayGain、键位、媒体键开关、主题等。

【播放状态 tuneux-fx-playlist.toml】
  播放列表、断点续播进度、ReplayGain 缓存、书签。

【插件核查日志 tuneux-fx-plugins.log】
  记录插件加载/验签结果（追加式）。

【存储位置】
  默认：可执行文件同目录；不可写时回退系统目录——
    Windows：%APPDATA%\tuneux-fx\
    macOS：  ~/Library/Application Support/tuneux-fx/
    Linux：  ~/.config/tuneux-fx/
