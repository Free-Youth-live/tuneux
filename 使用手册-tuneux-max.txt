============================================================
tuneux-max 使用手册（速查版）__VERSION__

不羁的青春（FreeYouth）· tuneux 系列 GUI 发行版
木兰宽松许可证 v2（MulanPSL-2.0）· 纯离线播放器

【定位】
  fx TUI 观感的 egui 图形界面：字符网格渲染、鼠标键盘双操控。
  模块自由组合（dock 分割树）、皮肤/字体/语言可换、命令模式。
  音频内核与 tuneux / tuneux-fx 完全同源：无损解码、Gapless 无缝
  切曲、断点续播、CUE 分轨、ReplayGain、介质风格 DSP 同口径。
  本版提供 macOS（Intel / Apple Silicon）与 Windows（x64）应用包；
  Linux 应用包暂未提供，后续支持 tuneux-max 的 Linux 版本——Linux 上
  可自行构建运行：cargo build --release -p tuneux-max。

【界面总览】
  菜单栏    八栏：文件/编辑/播放/音效/视图/工具/设置/帮助
            （数字键 1-8 直接打开对应菜单）
  传输条    播放键组 + 进度滑条（拖拽 Seek）+ 音量滑条
            （f2k 皮肤默认模块，右键状态栏可在模块菜单开关）
  顶部条    三个等高模块：当前曲目（60%）｜三桶频段（15%）｜
            电平（25%）——固定比例，任意窗宽下等高铺满
  中央区    dock 分割树（见下），默认：浏览器 ｜（列表/封面）
  状态栏    进度行；f2k 皮肤为技术行（FLAC | 1083 kbps | …）
  功能键栏  快捷键提示组：1-8 菜单 · e 均衡器 · ? 帮助

【dock 布局系统】（模块自由组合，与 fx 的面板互斥不同）
  · 加装模块：视图 → 模块（√ = 在树里）；或右键任一模块标题带
    → 水平/垂直拆分加装 / 更换为…（f2k 同款，钻取分页选模块）
  · 关闭模块：右键模块标题带 → 关闭模块
  · 调整大小：拖分割条；双击回 50/50
  · 交换两侧：右键分割条；改分割方向：Shift+右键分割条
  · 拖拽换位：拖模块标题带到另一模块上松手
  · 小模块（封面/歌词/EQ/压缩器/指针表）加装时纵向堆叠在右列
  · 布局预设：视图 → 布局预设 → 保存当前布局；或命令
    preset-save / preset-load / preset-del / preset-list
  · 全部关闭后：中央提示加装入口；整棵布局持久化

【可用模块】（视图 → 模块，共 12 个）
  浏览器 / 播放列表 / 频谱（v 键在 频谱↔示波器 间切换）/
  封面 / 歌词 / 均衡器（十段+预设）/ 压缩器（五参数）/
  波形（全曲包络条 + 播放位置 + 点击跳转 seek）/
  滤波器（截止频率 + 谐振 Q，立体旋钮拖拽调参）/
  可视化（可视化插件产出的字符画）/
  DSP 链（EQ → 压缩器 → 滤波器 链路总览）/
  指针表——灰阶 2.5D 字符网格的 VU 指针表（L/R 双表，
  浮起表框/凹陷盘壁/指针投影，针带 300ms 弹道物理）
  · 模块内容超空间时自动滚动（EQ/压缩器双向；列表/浏览器/歌词横向）
  · 浏览器工具行：↑ 上级目录 / ⌂ 主目录两个
    独立按钮（悬停有提示）；其后是可点面包屑路径——点击任意
    目录名直接跳到该位置（路径过长只留尾部 4 段 + 省略号）；
    Backspace 上级、/ 搜索、双击进目录/播放等均照旧

【鼠标操作】
  单击        选中行/项；分组头单击 = 折叠↔展开；面包屑路径段 = 跳转该目录
  双击        播放曲目 / 进入目录 / 重置分割条比例（滑条双击回默认）
  右键        行菜单（播放/移除…）；模块标题带 = 模块菜单；
              分割条 = 交换两侧；空白处 = 添加菜单；状态栏 = 模块开关
  拖拽        分割条改比例；模块标题带换位；浏览器行拖入列表；
              进度/音量/EQ/滑条拖动调值
  滚轮        悬停哪个列表滚哪个（互不串扰）；fx 端 = 移动选中；
              滑条/推子悬停滚轮微调（Shift 加速）
  右键频谱区  放大频谱字符（独立缩放）

【键盘快捷键】
  ?                   关于弹窗
  Cmd/Ctrl+O          打开文件（多选；mac 为 Cmd+O，Windows/Linux 为 Ctrl+O）
  空格       播放/暂停            n / p      下一曲/上一曲
  ←/→        快退/快进 5 秒       +/-        音量增减
  r / s      循环/随机切换        m / [ ]    介质风格
  a          加入当前条目          d          移除选中
  x 两次     清空列表（3 秒内二次确认）
  b / c / l  浏览器/封面/歌词 模块装卸
  v          频谱模块装卸/切示波器
  g          播放列表分组（专辑）视图切换
  /          搜索（浏览器或列表，Enter 首个匹配，Esc 退出）
  :          命令模式（见下）
  Tab        焦点 浏览器↔列表      ↑↓/jk      行选择
  Enter      进入/播放             Backspace  上级目录
  e          均衡器（未开=加装模块，已开=启用切换）
  i/Alt+Enter 属性弹窗（选中行优先，无选中回落当前曲）
  1-8        打开菜单             u          重载已装插件
  q          退出

【菜单要点】（数字 1-8 直开对应栏）
  播放顺序  播放 ▸ 播放顺序：六档单选（顺序/单曲循环/列表循环/
            随机曲目/随机专辑/真随机），点选即写入定值组合；
            随机三档自带列表循环（一轮播完重洗再播、不间断）——
            与 s 键的差别：s 只切随机、不动循环，随机开而循环关
            时一轮播完即停
  书签      播放 ▸ 书签 ▸ 添加/列表…/删除…；弹窗内点击或 Enter
            跳转、✕ 删除、Esc 关闭
  插件管理  工具 › 插件管理…：plugins/ 清单 + 装载状态 + 核查
            信任级（只读；u 或界面按钮重载）
  快捷键一览 帮助 › 快捷键一览…（内容自菜单表生成，随版本同步）
  属性      编辑 › 属性（i / Alt+Enter）：标签 / 技术参数 / 路径

【命令模式】（: 进入 · Enter 执行 · Esc 取消）
  vol 0-100              设音量
  repeat off|list|single 循环模式
  save-m3u               导出列表到 浏览器目录/playlist.m3u
  load-m3u [路径]        载入 m3u（后台读标签，万首不卡）
  bm                     当前位置加书签（同曲重打=更新）
  bm-list                列书签            bm-jump n   跳到书签
  bm-del n               删书签
  preset-save [名]       存布局预设        preset-load 名|序号  载入
  preset-del 名|序号     删预设            preset-list 列预设
  help                   打开关于
  未知命令会提示；命令与 fx 端语义同源

【皮肤 · 模块 · 字体 · 语言】（设置菜单）
  皮肤选择  内置五套：fx DOS（默认，深蓝底青框黄键号）/ Terminal
            （纯黑白）/ f2k 暗色 / f2k 经典浅色 / 科技深色；
            f2k 暗色默认全开（列头带/技术状态栏/频谱坐标轴/组头下划线/
            传输条/分组封面）；另有 plugins/ 皮肤插件供色
  模块      结构模块按皮肤给默认集，可逐个开关（每皮肤独立记忆）
  字体      内置 Sarasa Mono SC（更纱黑体·等宽简体，v1.0.42 官方
            原件，唯一自带字体）——「字体」菜单默认隐藏；向 fonts/
            投放 .ttf/.otf 后自动现身可选（半角/全角 2:1 列对齐不变）
  语言选择  内置中文 + locales/*.txt 扫描

【播放特性】
  · 播完自动切下一曲；连续 10 首失败自动停（防全损列表刷屏）
  · Gapless 无缝：下一曲预载，曲间零间隙（CUE 分轨无缝衔接）
  · 断点续播：切曲/暂停/退出记位置，重播接着听（结尾 5 秒内视为
    听完）；CUE 分轨书签记分轨内偏移
  · CUE：.cue 自动展开分轨；同名整轨镜像自动跳过防重复
  · ReplayGain：实测增益缓存（播完归档，下次免重测），持久化
  · 大目录导入：多线程并行读标签（目录遍历+标签工人池），
    UI 全程不卡

【数据与持久化】
  配置/布局/书签/预设/断点/增益缓存 随配置文件持久化；
  播放列表状态（曲目/选中/循环/随机）重启恢复。
  生成的数据文件（首次运行后落盘，共三个）：
  · tuneux-max.toml —— 主配置（界面状态/键位/音量/dock 布局等）
  · tuneux-max-playlist.toml —— 播放状态（播放列表/断点续播位置/
    ReplayGain 增益缓存）
  · tuneux-max-plugins.log —— 插件装载核查日志（追加式）
  落点规则（exe 同目录可写 → 便携模式；不可写 → 系统配置目录
  ~/Library/Application Support/tuneux-max/）：
  · 从可写位置启动（桌面/下载/U盘，含用户拖入 /Applications 的
    常规安装——bundle 归用户所有，Contents/MacOS/ 实测可写）→
    数据文件写入 .app 内部 Contents/MacOS/（便携模式）
  · 从只读位置启动（首次下载的隔离转译运行、DMG 只读挂载、
    管理员安装的只读 bundle）→ 回退系统配置目录
  ⚠ 数据位置随「从哪里启动」而定：换位置启动会像丢了配置——
    实际是数据留在原处（旧 .app 包内或系统目录）不会自动迁移。
    建议：要么固定从一处启动；要便携携带就整个 .app 连同数据
    一起拷，始终从同一位置运行。
  使用手册与第三方声明：分发包内与 .app 同级一份（开箱可见），
    bundle 的 Resources/ 内各留一份（右键 app → 显示包内容，
    .app 单独流转时不丢）；两份同源同版。

【边界与诚实说明】
  · 媒体键（键盘多媒体键）：Linux/Windows 生效，macOS 无系统
    接口静默缺失
  · 布局预设不含模块内部状态（EQ 参数等由各自机制持久化）
  · 标签编辑/格式转换：占位（与 fx 同口径）
  · 可视化模块靠已签名的「可视化-*.wasm」插件出画面——随包附带
    能量条与频谱瀑布两款（后者为 8 行时间历史瀑布，与实时频谱互补）
