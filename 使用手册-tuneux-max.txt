============================================================
tuneux-max 使用手册 __VERSION__
============================================================

不羁的青春（FreeYouth）· tuneux 系列 GUI 发行版
木兰宽松许可证 v2（MulanPSL-2.0）· 纯离线播放器

【定位】
  egui 原生图形界面：菜单栏、顶部三栏条、文件浏览器 / 封面、
  播放列表、歌词、频谱、状态栏和功能键栏。
  音频内核与 tuneux / tuneux-fx 共用 tuneux-corex：解码、Gapless、
  CUE 分轨、断点续播、ReplayGain、介质风格 DSP。
  0.6.2 仅提供源码，不发布 max 二进制发行包；可自行构建：
  cargo build --release -p tuneux-max。

【界面总览】
  菜单栏    文件 / 播放 / 音效 / 视图 / 设置 / 帮助。
  顶部条    当前曲目（60%）｜三桶频段（15%）｜电平（25%）。
  左侧      文件浏览器或专辑封面。
  中央      播放列表，可按曲名、路径、专辑或 CUE 标题过滤。
  右侧      可选歌词面板。
  底部      可选频谱 / 可视化插件、命令条、状态栏、快捷键提示。

【文件浏览器：鼠标与键盘】
  鼠标单击          选中文件或目录。
  鼠标双击          打开目录，或加入并播放文件。
  鼠标「返回上一级」按钮  返回父目录；已在根目录时不执行操作。
  ↑ / ↓            移动选中项。
  Enter            打开选中目录，或加入并播放选中文件。
  Backspace        返回上一级目录（搜索文本编辑时仍用于删字）。
  /                聚焦递归搜索框；输入名称关键字即时过滤。
  搜索结果          单击选择，双击或 Enter 打开 / 播放。
  Esc              清空搜索和过滤状态。

【主要快捷键】
  空格             播放 / 暂停；到末尾后重新播放。
  n / p            下一曲 / 上一曲。
  ← / →            快退 / 快进 5 秒（CUE 限本分轨区间）。
  + / -            音量增减。
  r                循环：顺序 → 单曲循环 → 列表循环。
  s                随机：关 → 曲目 → 专辑 → 真随机。
  m                介质：无 → 磁带×4 → 黑胶×4。
  a                加入浏览器选中项。
  d / Delete       移除播放列表选中项。
  x                清空播放列表。
  b                显示文件浏览器。
  c                文件浏览器 / 专辑封面切换。
  l                显示 / 隐藏歌词。
  v                频谱：关 → 半屏 → 全屏。
  e                打开 / 关闭均衡器面板。
  :                命令模式；Enter 执行，Esc 取消。
  ?（Shift+/）      关于。
  q / Ctrl+Q       退出并保存。
  Ctrl / Alt 与其它字母的组合不触发默认单键动作；自定义 keymap 除外。

【播放与 CUE】
  · 顺序、单曲循环、列表循环及四种随机模式可持久保存。
  · 顺序播放预载下一曲；无缝切曲只更新界面，不重复起播。
  · 播放失败按共享失败计数自动跳曲，连续 10 首失败后停止；
    手动点播恢复自动跳曲能力。
  · 同名 `.cue` 的整轨自动展开；也可直接选择 `.cue` 文件。
  · CUE 分轨按实际音频路径和第一轨起点定位，部分或全部去重后
    再次打开仍从第一轨开始；数据轨跳过并提示。
  · 快进快退、进度和歌词均使用分轨内时间；末轨时长按整文件
    时长减分轨起点计算，不重复扣减。
  · 普通文件保存断点，重启后从上次位置继续；距结尾 5 秒内从头播。
    CUE 保存当前分轨号，不把分轨位置写成整轨断点。

【ReplayGain 与介质】
  · 「音效 › ReplayGain 响度归一」开关默认关闭，目标为 −14 LUFS。
    首次播放分析，完成后缓存；后续播放及重启后按缓存增益应用。
    对应配置：tuneux-max.toml 的 replay_gain、播放状态中的增益表。
  · 「音效 › 介质」可逐档选择，m 键循环：无 → 磁带×4 → 黑胶×4。
    仅改变声音，不改变面板；playback_medium 持久保存。
  · 均衡器十段和压缩器五参数在「音效」菜单打开；支持旁路和复位。

【插件与皮肤】
  · 默认皮肤为「终端原生」；可选择通过验签的第一方皮肤插件。
    manifest ID、文件名和签名必须一致，init 后才读取调色板；
    缺失或失败时回落系统原生深浅色。
  · 均衡器 / 压缩器 / 可视化插件复用 tuneux-pinx 验签与能力沙箱。
  · 可视化面板可使用随包「可视化-能量条」「可视化-频谱瀑布」。
  · 「音效 › 插件管理」查看已加载清单并重新验签装载。
  · 第三方插件安装通道未开放，无联网功能。

【M3U 与命令模式】
  quit / q                 退出
  volume <0-100>           设置音量百分比
  repeat off|single|list   设置循环模式
  shuffle off|tracks|albums|true_random
                           设置随机模式
  save-m3u <路径>          保存列表；同一音频文件仅写一行
  load-m3u <路径>          替换当前列表；相对路径按 M3U 所在目录解析，
                           同名 CUE 自动展开，提示实际新增条目数
  clear                    清空播放列表
  about                    关于
  help                     显示命令帮助

【数据与持久化】
  配置：tuneux-max.toml —— 音量、循环、随机、语言、默认皮肤、
        浏览器比例、ReplayGain、介质、媒体键和自定义键位。
  状态：tuneux-max-playlist.toml —— 播放列表、当前文件、当前 CUE
        分轨号、普通文件断点、ReplayGain 缓存。
  默认写入可执行文件同目录；不可写时回退系统配置目录：
    Windows：%APPDATA%\tuneux-max\
    macOS：~/Library/Application Support/tuneux-max/
    Linux：~/.config/tuneux-max/
  每 5 秒及正常退出时保存。配置或播放状态损坏时先备份为
  <原文件>.corrupt.bak，并停止本次会话写回，不用默认值覆盖原文件。
  旧状态没有 current_cue 字段时按普通兼容路径加载，无需手工迁移。

【语言与媒体键】
  · 内置中文和随包 locales/en.txt 英文，切换后立即生效。
  · Linux 经 MPRIS、Windows 经媒体键钩子；可在设置中关闭。
    macOS 暂不支持系统媒体键。
  · CUE 播放时桌面媒体标题显示分轨标题。

【FFmpeg 扩展格式】
  核心格式纯 Rust 解码；APE / WMA / FLV / TAK / AC3 / DTS / DSD 等
  由随包或系统 FFmpeg 子进程解码，缺失时提示，不影响核心格式。
  macOS 随包组件位于 .app/Contents/Resources/ffmpeg/；
  Windows 位于 tuneux-max.exe 同层 ffmpeg/。下载隔离的 macOS 包先执行：
    xattr -cr tuneux-max.app

【边界说明】
  · 当前为固定面板布局，不提供 dock 分割树、布局预设、书签、
    标签编辑或格式转换；README 不应把这些列为已提供功能。
  · 无网络能力，不收集任何数据；音频内核不自行联网。
